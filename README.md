 HARCATAKİP — KİŞİSEL GİDER VE BÜTÇE TAKİP UYGULAMASI
1. Projenin Amacı:
Katılımcıların HTML5, Bootstrap 5 ve ReactJS temel kavramlarını kullanarak tarayıcı tabanlı (LocalStorage destekli) interaktif bir tek sayfa uygulaması (SPA) geliştirmeleri ve bulut ortamında (Netlify) yayına almaları amaçlanmaktadır.
2. Kullanılan Teknolojiler: HTML5, Bootstrap 5, ReactJS (ES6+), LocalStorage API, GitHub, Netlify.
3. Proje Uygulama Adımları:   Kullanıcı yeni bir harcama kaydı (Başlık, Tutar, Kategori) ekleyebilmelidir (Ekleme).   Eklenen tüm harcamalar ve toplam tutar dinamik kart/tablo yapısında görüntülenebilmelidir (Listeleme).   Mevcut bir harcama kaydının tutarı veya başlığı düzenlenebilmelidir (Güncelleme).   İstenen harcama kaydı listeden ve LocalStorage'dan silinebilmelidir (Silme).
4. Teslim Çıktıları: Proje ekran görüntüsü, Public GitHub Repository linki ve canlı Netlify uygulama linki.
